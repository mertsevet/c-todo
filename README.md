# c-todo

C dilini tekrar öğrenmek için sıfırdan yazdığım terminal tabanlı to-do uygulaması.
Java/C# geçmişim var, C'yi teoriden değil proje yazarak hatırlamak için başladım.

## Amaç
Her gün küçük bir özellik ekleyerek C'nin temel konularını pratikte kullanmak:
struct, diziler, pointer, dinamik bellek, dosya okuma/yazma.
